# Wisp privacy policy

Last updated: October 10, 2026

## Monitoring stays on your Mac

Wisp reads available system activity to display resource usage. It has no user account and includes no advertising, tracking, or third-party analytics SDKs. Wisp does not transmit monitoring data to its developer or other parties.

## Software updates

The direct-download edition uses Sparkle to check for software updates on GitHub when you choose Check for Updates, or approximately once per day while Wisp is running unless you disable daily checks in Settings. Daily checks are on by default; a saved choice to disable them is preserved. Updates are downloaded and installed only after you choose to proceed. These requests include standard connection information such as your IP address and an application/version user agent; system profiling is disabled. Monitoring data, app names and saved history are never included. Update preferences are stored locally. GitHub and its download infrastructure process requests under their own privacy policies.

## Local history

Wisp saves overall CPU and memory snapshots once per minute in its local Application Support directory. History older than approximately 30 days is pruned daily while the app is running. App names, process details, and other live readings are held in memory and are not written to the history database. Settings are saved locally using macOS preferences.

## Your controls

You can delete saved monitoring history in Wisp Settings. New snapshots continue to be recorded while monitoring runs. Launch at login is optional and off until you enable it. Use Quit Wisp Completely to stop monitoring, including the menu bar.

## Downloads and support

GitHub hosts downloads and public support issues. Homebrew can download and install the app. These services operate under their own privacy policies; the app's lack of telemetry does not mean the download services collect no information. Information you voluntarily post in GitHub issues is public. Avoid sharing private process names, screenshots or logs containing personal information.

Privacy questions can be raised through [Wisp's support issues](https://github.com/PhanithNY/wisp-releases/issues).
